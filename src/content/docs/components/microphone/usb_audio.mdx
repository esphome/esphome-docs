The `usb_audio` microphone platform records audio from the input of a USB Audio Class device, such as a USB
speakerphone, headset or sound card, connected through the [USB Audio](/components/usb_audio/) component.

This platform only works on the ESP32-S2, ESP32-S3, ESP32-P4 and ESP32-H4 with the
[ESP-IDF framework](/components/esp32/#framework).

> [!WARNING]
> Audio and voice components consume a significant amount of resources (RAM, CPU) on the device.
>
> **Crashes are likely to occur** if you include too many additional components in your device's
> configuration. In particular, Bluetooth/BLE components are known to cause issues when used in
> combination with Voice Assistant and/or other audio components.

```yaml
# Example configuration entry
microphone:
  - platform: usb_audio
    id: usb_mic
```

## Configuration Variables

- **usb_audio_id** (*Optional*, [ID](/guides/configuration-types#id)): The ID of the
  [USB Audio](/components/usb_audio/) component to use. Only needed when more than one is configured.
- **sample_rate** (*Optional*, positive integer): The sample rate of the stream, from `8000` to `96000`.
  Defaults to `16000`.
- **bits_per_sample** (*Optional*, enum): The bit depth of the audio samples. One of `8bit`, `16bit`, `24bit` or
  `32bit`. Defaults to `16bit`.
- **num_channels** (*Optional*, positive integer): The number of channels, `1` or `2`. With `2`, each sample of the
  first channel is followed by a sample of the second channel. Defaults to `1`.
- **buffer_size** (*Optional*, positive integer): The size in bytes of the USB Audio Class driver's ring buffer for
  this stream. A larger buffer tolerates longer delays in reading the audio, but uses more memory.
  Defaults to `6400`.
- All other options from [Microphone](/components/microphone/#base-microphone-configuration).

The device must support the configured `sample_rate`, `bits_per_sample` and `num_channels` exactly. If it does not,
the formats it supports are logged when it is plugged in; see
[Audio Format](/components/usb_audio/#audio-format).

The defaults match the 16 kHz, 16-bit mono audio that [Micro Wake Word](/components/micro_wake_word/) and
[Voice Assistant](/components/voice_assistant/) need. If the device only records at another sample rate, add a
[Resampler Microphone](/components/microphone/resampler/). If the device only records in stereo, set
`num_channels: 2` and select a channel with the `channels` option of a
[Microphone Source](/components/microphone/#microphone-source-configuration).

When the device is unplugged while recording, the microphone waits for it and resumes recording when it is plugged
in again.

## Example

A USB headset that only records 48 kHz stereo audio, resampled to 16 kHz mono for the voice assistant:

```yaml
microphone:
  - platform: usb_audio
    id: usb_mic
    sample_rate: 48000
    num_channels: 2

  - platform: resampler
    id: resampled_mic
    microphone:
      microphone: usb_mic
      channels: 0
    sample_rate: 16000

voice_assistant:
  microphone: resampled_mic
```
