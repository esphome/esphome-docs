---
title: "RX8111 Time Source"
description: "Read and set time using an Epson RX8111CE real-time clock."
---

The RX8111 time platform reads UTC time from an Epson RX8111CE real-time clock (RTC) over
[I²C](/components/i2c/). Configure the I²C bus separately.

```yaml
time:
  - platform: rx8111
    id: rtc
```

The RTC is read on startup and periodically at the base time platform's `update_interval` (15 minutes by default).
The RTC will **not** automatically be set from system time. A read will not synchronize the system clock if the RTC
reports power loss or oscillator stop, or if its BCD time, calendar date or weekday is invalid. The invalid-time
flags are cleared only after an explicit, successful write of trusted time.

## Configuration Variables

- **id** (*Optional*, [ID](/guides/configuration-types#id)): ID used by the actions and lambdas.
- **address** (*Optional*, int): I²C address; defaults to `0x32`.
- All other options from [Base Time Configuration](/components/time/#base_time_config).

## Synchronizing Time

To set the RTC when a trusted time source becomes available, call `rx8111.write_time` explicitly:

```yaml
time:
  - platform: rx8111
    id: rtc
    update_interval: never
  - platform: homeassistant
    on_time_sync:
      then:
        - rx8111.write_time: {id: rtc}
```

This example also requires a working [Home Assistant time source](/components/time/homeassistant/).
`rx8111.write_time` writes valid system UTC time to the RTC; it will not write dates outside 2000–2099. A
successful write clears the time-validity flags without clearing alarm, timer, update or event flags.
`rx8111.read_time` requests an additional RTC read and synchronizes the system clock only if the RTC time is valid:

```yaml
on_...:
  - rx8111.read_time: {id: rtc}
```

Both actions can omit `id` when only one RX8111 time source is configured. RX8111 alarm, timer, event capture,
FOUT and backup power configuration are not available in this initial time platform.
