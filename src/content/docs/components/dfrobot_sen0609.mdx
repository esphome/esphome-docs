The `dfrobot_sen0609` component lets you use the DFRobot SEN0609 and SEN0610 24GHz mmWave radars (C4001 family)
with ESPHome. The radar reports human presence and, in speed and distance mode, the distance, speed and signal energy
of a moving target. The SEN0609 has a detection range of up to 25 m and the SEN0610 up to 12 m.

The component talks to the module's text command line over UART, so set the module's communication switch to UART.
A [UART](/components/uart/) is required, with both `tx_pin` and `rx_pin`, `baud_rate` set to `9600`, `parity` set to
`NONE` and `stop_bits` set to `1`.

```yaml
uart:
  tx_pin: GPIOXX
  rx_pin: GPIOXX
  baud_rate: 9600

dfrobot_sen0609:

binary_sensor:
  - platform: dfrobot_sen0609
    has_target:
      name: Presence
```

## Hub Component

At every boot the hub stops the sensor, writes the run mode and the UART output settings, reads the versions when
[text sensors](#text-sensor) are configured, and starts the sensor again. These settings are applied each time instead
of being saved on the module.

The module ignores commands that arrive too quickly, so the hub sends one command at a time and retries a command
that is rejected or not answered, up to three times. When the module does not answer at all, the component shows a
warning status and tries again after 30 seconds.

### Configuration Variables

- **id** (*Optional*, [ID](/guides/configuration-types#id)): Manually specify the ID for this component. Necessary
  if you want to define multiple instances of this component.
- **uart_id** (*Optional*, [ID](/guides/configuration-types#id)): The ID of the [UART](/components/uart/) to use.
  Required if you have multiple UARTs configured.
- **mode** (*Optional*, string): The run mode of the radar. Defaults to `presence`.

  - `presence`: The radar reports whether a person is present.
  - `speed_and_distance`: The radar reports the distance, speed and energy of a moving target. Needed for the
    [sensors](#sensor).

## Binary Sensor

```yaml
binary_sensor:
  - platform: dfrobot_sen0609
    has_target:
      name: Presence
```

### Configuration Variables

- **dfrobot_sen0609_id** (*Optional*, [ID](/guides/configuration-types#id)): The ID of the hub component. Required
  if you have multiple hubs configured.
- **has_target** (*Optional*): `true` when the radar detects a target. In `presence` mode this is a person being
  present; in `speed_and_distance` mode it is a moving target. All options from
  [Binary Sensor](/components/binary_sensor/).

## Sensor

The sensors need the hub `mode` to be `speed_and_distance`; configuration validation fails otherwise. When no target
is detected, the sensors report an unknown state.

```yaml
dfrobot_sen0609:
  mode: speed_and_distance

sensor:
  - platform: dfrobot_sen0609
    target_distance:
      name: Target Distance
    target_speed:
      name: Target Speed
```

### Configuration Variables

- **dfrobot_sen0609_id** (*Optional*, [ID](/guides/configuration-types#id)): The ID of the hub component. Required
  if you have multiple hubs configured.
- **target_distance** (*Optional*): The distance to the target in metres. All options from
  [Sensor](/components/sensor/).
- **target_speed** (*Optional*): The speed of the target in metres per second. All options from
  [Sensor](/components/sensor/).
- **target_energy** (*Optional*): The signal energy reflected by the target, without a unit. All options from
  [Sensor](/components/sensor/).

## Text Sensor

The versions are read from the module at boot.

```yaml
text_sensor:
  - platform: dfrobot_sen0609
    version:
      name: Software Version
    hardware_version:
      name: Hardware Version
```

### Configuration Variables

- **dfrobot_sen0609_id** (*Optional*, [ID](/guides/configuration-types#id)): The ID of the hub component. Required
  if you have multiple hubs configured.
- **version** (*Optional*): The software version of the module. All options from
  [Text Sensor](/components/text_sensor/).
- **hardware_version** (*Optional*): The hardware version of the module. All options from
  [Text Sensor](/components/text_sensor/).
