The `fusb302b` component supports the onsemi [FUSB302B](https://www.onsemi.com/products/interfaces/usb-type-c/fusb302b)
USB Type-C and Power Delivery (PD) controller. It acts as a PD sink: when a USB-C power source is attached, it
negotiates a power contract for a fixed supply voltage of up to 20 V.

The FUSB302B communicates over [I²C](/components/i2c/), so an I²C bus must be configured. The component is
only supported on ESP32.

```yaml
# Example configuration entry
fusb302b:
  interrupt_pin: GPIOXX
  request_voltage: 20
```

## Configuration Variables

- **interrupt_pin** (**Required**, [Pin](/guides/configuration-types/#pin)): The GPIO pin connected to the `INT_N`
  output of the FUSB302B. `INT_N` is an open-drain output; the internal pull-up of the pin is enabled by default.
- **request_voltage** (**Required**, int): The voltage in volts to request from the source, from `5` to `20`. See
  [Power Negotiation](#power-negotiation).
- **id** (*Optional*, [ID](/guides/configuration-types/#id)): Manually specify the ID used for code generation.
- **address** (*Optional*, int): The I²C address of the FUSB302B. Defaults to `0x22`, the address of the
  FUSB302BMPX. The FUSB302B01MPX, FUSB302B10MPX and FUSB302B11MPX use `0x23`, `0x24` and `0x25`.
- **i2c_id** (*Optional*, [ID](/guides/configuration-types/#id)): The ID of the [I²C bus](/components/i2c/) the
  FUSB302B is connected to. Required when more than one I²C bus is configured.

## Power Negotiation

USB PD sources offer a list of fixed supply voltages, chosen from 5, 9, 12, 15 and 20 V. The component requests the
highest one that does not exceed `request_voltage`, at the maximum current the source offers for it. For example,
with `request_voltage: 12` and a source offering 5, 9, 15 and 20 V, the component requests 9 V.

The component stays at 5 V Type-C default power when:

- The source does not support Power Delivery, or does not send its capabilities after the component asks for them
  and sends a soft reset.
- The source rejects the request, or does not report the new supply as ready in time.

The negotiation runs in a dedicated FreeRTOS task, so replies to the source meet the PD timing requirements even
while the main loop is busy. The first measurement of the CC lines is made 2 seconds after boot, to give the source
time to settle.

> [!WARNING]
> The requested voltage appears on VBUS. Make sure that everything connected to VBUS, such as the voltage regulator
> that powers the ESP32, is rated for the highest voltage that `request_voltage` allows.
