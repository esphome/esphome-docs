The `m5stack_4relay` component controls the four relays of the
[M5Stack 4-Relay Unit](https://docs.m5stack.com/en/unit/4relay) over [I²C](/components/i2c/). Each relay switches
up to 250 V AC or 28 V DC at 10 A, and the unit's LEDs follow the relays.

<Image src="/images/m5stack_4relay.png" width={400} height={400} layout="constrained" alt="M5Stack 4-Relay Unit" />

```yaml
# Example configuration entry
m5stack_4relay:
  id: relay_hub

switch:
  - platform: m5stack_4relay
    name: "Relay 1"
    channel: 1
  - platform: m5stack_4relay
    name: "Relay 2"
    channel: 2
```

## Hub configuration variables

- **id** (*Optional*, [ID](/guides/configuration-types#id)): Manually specify the ID used for code generation.
- All other options from [I²C Device](/components/i2c/).

## Switch configuration variables

- **channel** (**Required**, int): The relay to control, `1` to `4`.
- **m5stack_4relay_id** (*Optional*, [ID](/guides/configuration-types#id)): The unit the relay belongs to. Required
  with more than one unit.
- **restore_mode** (*Optional*): Defaults to `DISABLED`. The unit keeps its relays while it stays powered, so after a
  reboot of the ESP a switch shows the relay as it is instead of changing it. Set one of the other
  [restore modes](/components/switch#config-switch) to drive the relay at boot.
- All other options from [Switch](/components/switch#config-switch).
