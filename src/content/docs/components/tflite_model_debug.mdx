---
description: "Debug tooling for TFLite Micro models (CRC32, architecture, tensors)"
title: "TFLite Model Debug"
---

The `tflite_model_debug` component is a **library-only component**: it does not expose YAML configuration and is
loaded automatically as a dependency of the `tflite_micro_runtime`
component and of the third-party components that consume it.

Everything is guarded by the `DEBUG_TFLITE_MICRO_HELPER` define emitted when the `debug: true` option is set
on the consuming `tflite_micro_runtime` component. When enabled it provides CRC32 model verification, model
architecture inspection, tensor input/output statistics and quantization analysis, parameter sweeps for
tuning preprocessing configuration, and watchdog feeding during long debug operations.
